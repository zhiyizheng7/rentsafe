# 評審 Q&A 備忘（QA_PREP）

每題寫出 **30 秒內講得完**的回答稿，指定主答人。排練時全員輪流被問。
原則：不確定就說「目前還沒做到」，承認限制比被追問出破綻好。

| # | 可能的提問 | 回答要點 | 主答人 |
|---|---|---|---|
| 1 | **哪些是真的、哪些是示範？** | 照 DEMO_FLOW 的分工誠實說明：租金行情是真實資料、合約是規則比對、建物登記與凶宅等是展示未來串接 | |
| 2 | AI 實際做了什麼？ | 說清楚現在的做法（規則比對、資料統計）與接下來要加的（例如 LLM 補充說明），不要講成已經有的 | |
| 3 | 資料從哪裡來？可靠嗎？ | 實價登錄是官方開放資料，有期別與樣本數；說明樣本不足時怎麼處理 | |
| 4 | 合約規則的依據是什麼？ | 內政部《住宅租賃契約書範本》（113/7/8 修正版）與簽約注意事項，每條規則有條號與頁碼。分清楚三種語氣：範本明載無效、超過範本上限、與範本預設不同；不說成「違法」。強調是風險提示、不是法律意見 | |
| 5 | 誤判怎麼辦？ | 每個提示附原因與依據，由使用者最終決定；建議必要時諮詢專業 | |
| 6 | 建物登記、坪數、違建怎麼查？ | 說明資料來源與取得方式的現況與限制（授權、成本）；沒做出來就照實說是未來規劃 | |
| 7 | 凶宅是怎麼查的？ | 老實說：沒有官方凶宅資料庫。但內政部的住宅租賃契約書範本，在附件一「租賃標的現況確認書」第 8 項要求出租人說明是否曾發生兇殺、自殺、一氧化碳中毒或其他非自然死亡。我們的模組是「風險提醒」：提醒租客要求房東填寫，並補充查新聞、問管理員的方法。注意：房東可勾「不知道」，所以不等於保證沒有 | |
| 8 | 跟 591 等現有平台有什麼不同？ | 站在租客這邊做查核，而不是媒合或刊登 | |
| 9 | 永續價值在哪？ | 降低租屋糾紛與詐騙損失、提升市場透明度、保護經濟弱勢的學生租客 | |
| 10 | 能擴展到真實使用嗎？ | 下一步：串接真實資料來源、擴充規則庫、與學校或政府單位合作 | |
| 11 | 現在的限制是什麼？ | 範圍有限、規則需持續更新、不能取代專業法律諮詢 | |
| 12 | 使用者上傳的資料怎麼處理？ | （確認實際做法後填寫，例如不儲存輸入內容） | |
