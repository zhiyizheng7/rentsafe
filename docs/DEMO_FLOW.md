# 攤位 6 分鐘流程（DEMO_FLOW）

決賽有兩個環節：台上 **8 分鐘**成果發表，接著四位評審分流到各組攤位做**約 6 分鐘**的實作評比與 Q&A。
評審會親手操作、當場追問，所以展示要能獨立跑、不依賴會場網路。

## 定位

不改方向，不做遊戲、不出題。核心仍是 `/check` 與 `/contract`；補上展示模式（F1）讓評審 30 秒上手，再加一個「情境看房」（F8，`/tour`）當體驗入口，評審先像實地看房一樣探索，再一鍵帶去 RentSafe 查核。F8 若沒做完，流程直接跳過這一段。

## 6 分鐘分配

| 時間 | 做什麼 |
|---|---|
| 0:00–0:30 | 一句話破題；評審掃 QR 或直接操作 |
| 0:30–1:30 | 情境看房（F8）：評審點熱點探索，按「帶著這間房去查核」（沒有 F8 就從物件查核直接開始） |
| 1:30–3:00 | 物件查核：看體檢報告與租金行情（真實資料） |
| 3:00–4:00 | 合約審查：載入預設合約，看條款風險 |
| 4:00–6:00 | Q&A（見 QA_PREP.md） |

一句話破題（草稿，可改）：
「租屋詐騙與不公平條款很常見，RentSafe 讓你 60 秒內看清房子與合約哪裡有風險、為什麼。」

## 展示模式要有的東西（F1）

- [x] 預設案例清單，一鍵載入，不用評審自己找資料
- [x] 一鍵重置，評審之間快速換人
- [ ] 拔掉網路也能跑完整輪
- [ ] 手機掃 QR 可操作
- [x] 示範資料有標示，真實資料有來源與期別（F6）

## 現場必備

- [ ] 備用操作影片（無網路時播放）
- [ ] 至少一位熟悉系統的成員駐守攤位；**正式評比時盡量全員到齊**
- [ ] 海報 11/16 08:50 前張貼；11/15 15:00–16:30 可提前進場佈置與測試
- [ ] 設備、充電器、轉接頭
- [ ] 發表代表帶學生證

## 誠實說明哪些是真的

評審一定會問。先講好分工：

| 部分 | 要怎麼說 |
|---|---|
| 租金行情 | 真實：實價登錄租賃資料，期別與樣本數畫面上有 |
| 合約條款 | 規則比對，規則來源見法規核對文件 |
| 建物登記、坪數、違建、凶宅 | 展示：未來要串接的資料來源與流程（若 11/11 前沒做出真實版就照實說） |
